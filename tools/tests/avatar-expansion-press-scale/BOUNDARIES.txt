Run with python3 -I run.py --source-root PATH --output PATH.
Use --revision 246e3e957ae5cea1ecff6d7a6a6db3e47be69bb5 for the exact-base negative control.

The runner extracts the actual Control mouseDown, mouseUp, send, updateState and stateDidUpdate methods, the actual layer press-animation implementation, and the actual header expansion setter from the selected source. A structural check verifies that table row-height invalidation synchronously invokes view.set(item:).

AppKit NSView, NSEvent, CALayer and spring animation objects are real. Events are created in memory and delivered directly to the extracted handlers. Held-button and pointer-inside state are injected so no operating-system input is generated or read. Delayed transition callbacks are drained deterministically. Unused menus, signal plumbing and glass touch effects are inert stand-ins.

The fixture's header layout and music strip are synthetic. It tests animation lifetime and geometry of the retained transform, not Telegram's complete renderer or pixel screenshots. It checks both strip heights, fresh swipe, click followed by swipe, ordinary control release, sibling-control isolation and existing expansion callbacks.

The test creates no windows, opens no Telegram client, accesses no account/database/media and builds no SwiftPM dependency graph. It does not establish the source revision of the user's recording or constitute user acceptance.

Python isolated mode (-I) is required. Output and compiler-lock paths must be outside both the selected source root and the harness repository. --revision reads Git objects from the harness repository, including when --source-root is a materialized tree without Git metadata.

Every compiler invocation uses swiftc -j1 under fcntl.flock. Pass --compiler-lock PATH to coordinate with other runners; otherwise the lock is compiler.lock in the output directory. Outputs, generated source, binary and module cache are written only to the supplied output directory. No project/source/config/index changes are performed by the runner.
