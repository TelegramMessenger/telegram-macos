# Reaction callback lifetime verification

Run `python3 tools/tests/reaction-permissions/run.py` on macOS. The current fixture compiles actual production eligibility, permission, chip, quick-action and picker callback bodies with controlled collaborators. It passes 106 checks. It covers row replacement, weak ChatInteraction ownership, live rights restoration/revocation, boosts, personal bans and full message restrictions. No server requests are made.

PickerLifetimeHarness.swift is a committed diagnostic source under tools, not a shipping target member. Its current three checks cover production picker creation, release of the retired row while the picker exists, and release after closing. It uses shipping APIs and requires no private permission probe. Temporarily copy only the needed harness into ChatUI, call codexInstallPickerLifetimeEvidence(source: chatInteraction, parent: genericView) from ChatController.viewDidAppear, and build a separate disposable validation checkout. It records picker-lifetime.json below TELEGRAM_PICKER_EVIDENCE or the temporary directory.

The old native before/after JSON reports belong to an earlier six-check harness at revision 9d98d545, which included a temporary permission probe. That probe is not required by the current harness. Those reports are retained historical evidence, not current results or a rerun of the latest closure. The latest 106-check source result is ../current-checks.txt. A current full integration build compiles shipping code; it does not imply that the optional diagnostic harness was installed or that reactions were sent.
