Scope:
Header width is an independent minimum for the block, not extra padding alongside every code line. The fix preserves CoreText wrapping rather than clipping an oversized result or sacrificing body width. Baseline and current have identical line ranges for the main matrix.

The fix does not redesign header truncation when the entire available width is narrower than the header plus existing padding, and does not repair pre-existing cutout/finite-line truncation behavior. Finite-line controls check differential header sizing, not general quote truncation containment. Exact source/client parity, entities and font settings of the supplied screenshot remain unknown; native reproduction establishes the source defect, not a reproduction inside that user's Telegram session.

Every Swift compilation is -j1 and holds fcntl.flock on --compiler-lock (default: native-compiler.lock under --output). Pass the same external lock path when coordinating parallel native harnesses. Generated sources, compiler logs, run logs and SHA-256 provenance are written only under --output. No external dependencies or production configuration changes are required.
