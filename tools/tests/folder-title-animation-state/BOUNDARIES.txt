This executable extracts the production State, initial State construction, title-edit and animation-toggle closures, SidebarFolderModel animation getter/title updater, and sidebarUpdatingTitle body. Neither fixed nor baseline logic is reimplemented by the test.

ChatFolderTitle is extracted whole from TelegramCore pin 24638bc69bd083981b178dd1e7f921eebbf7fc46, including real Codable defaults. The ChatListFilter case declaration comes from that same pin (Codable conformance omitted because this test exercises title serialization rather than filter persistence). The new-folder title initializer is extracted from ChatListFilterPreferences at the source root or exact application base 246e3e957ae5cea1ecff6d7a6a6db3e47be69bb5.

Explicit boundary doubles: MessageTextEntity is an opaque Codable/Equatable token/range; ChatListFilterData is an opaque equality token; StringCodingKey is the Foundation coding-key adapter. Updated_ChatTextInputState and Environment carry text/entities/selection without AppKit attributed-string rendering; ExportedChatFolderLink is an unused equality placeholder. State mutation runs synchronously instead of ValuePromise/Atomic delivery. No account, persistence, API, GUI, or rendering is exercised.

The baseline always uses git show at the exact application base, compiles successfully, and must exit with assertion failures. Compilation errors are harness failures and are not counted as negative evidence. The fixed source root need not be the harness worktree, permitting the same suite to test a combined source tree. Baseline and pinned-model Git authority resolves from the runner's own repository, not the source-root historical HEAD. Run with python3 -I run.py --source-root ABSOLUTE_ROOT --output ABSOLUTE_EXTERNAL_OUTPUT; optionally --core-git-dir ABSOLUTE_CORE_OBJECT_DIRECTORY.

Each run sanitizes inherited GIT_* variables, gives swiftc one job, and uses output-local TMPDIR/module caches. Generated Swift, binaries, logs, and JSON evidence remain exclusively under --output. No SwiftPM or Xcode build occurs.
