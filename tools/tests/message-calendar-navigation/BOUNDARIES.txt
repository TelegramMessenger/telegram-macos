Ordinary message calendar keyboard and accessibility checks

run.py compiles actual CalendarController, CalendarMonthStruct, CalendarMonthController lifecycle and day activation method bodies into controlled account-free view/navigation fixtures. It links the real CalendarUtils Objective-C source supplied by --reference. Date arithmetic uses real Foundation calendars; keyboard modifier flags use real AppKit types. The --baseline <git-revision> --shared-only mode extracts the actual old controller and runs the same shared keyboard cases. This is method-boundary runtime testing, not the full Telegram controller or event loop.

--accessibility compiles the actual CalendarMonthView and CalendarDayButton classes against controlled TGUIKit rendering/control wrappers over real AppKit NSViews. It invokes real accessibility selectors and verifies date labels, disabled/selected/value states, retained child identities, range roles, detached/outgoing action guards and unchanged grid geometry across 168 months. No NSApplication, NSWindow, screen capture, live VoiceOver or synthetic UI event is created. Wrapper styling/animations and window focus behavior are not visual acceptance proof. Full CalendarUI separately typechecks against real dependency modules and SDK.

Both the ordinary and search calendars use a Gregorian Monday-first, left-to-right grid. This change follows existing geometry rather than partially redesigning RTL or locale week starts. AX full-date labels use the current app-language locale; hidden birthday years omit the internal sentinel year.

Keyboard movement changes focus only. Return and accessibility press use the same guarded day activation as pointer selection. In Select mode this only edits the selected date range; it never invokes clearing history. Clear-history confirmation code is unchanged. Arrows with Command, Control or Shift pass through, including VoiceOver Control-Option; plain arrows move a day/week and Option-Left/Right move a month. Escape ownership remains unchanged. Outgoing month views stop exposing/actioning their dates and handlers are removed on disappearance.

Run with python3 -I, explicit --output outside the source tree and the shared --compiler-lock path. Swift/Clang jobs serialize through that lock. Compilation requires at least8GiB free disk; only the owned process group is stopped below4GiB. Logs/commands/results and extracted source remain in the output directory. Caches, native executables and object files there are disposable after verification; source dependencies are not.
