U19 ordinary attachment individual spoilers native regression harness

Run with python3 -I tools/tests/attachment-individual-spoilers/run.py --source-root PATH --output PATH --compiler-lock PATH.
The optional lock defaults to OUTPUT/compiler.lock; concurrent native builds must pass a common --compiler-lock explicitly. Output and lock paths must be outside both source and harness repositories, checked before creating directories. The script rejects non-isolated Python, acquires an exclusive fcntl.flock before every swiftc invocation, uses -j1, and releases the lock before executing the fixture. Each compiler requires at least 8 GiB free disk space on source/output volumes; a supervised process group is terminated if free space drops below 4 GiB. Disk measurements are recorded. Runtime temporary files stay under OUTPUT/tmp. No app is launched. The compiler target is the host architecture at macOS 13.0 with the installed SDK, avoiding a default host target unsupported by the installed standard library.

Fixture substitutions
Visibility modifiers are removed in extracted blocks solely to permit inspection from one Swift fixture file. No behavior is rewritten in those blocks. Foundation, CoreGraphics and ImageIO are native. Telegram media, account context, Postbox protocol, signal plumbing, analytics, table/view classes and localization are small explicit fixture types, not real application modules. GroupedLayout executes its actual initializer/filter and move implementation against deterministic vertical tile frames, not the production collage measurement algorithm. Message construction and album slices execute actual previewMediaEntries code: IDs are global indices within that preview snapshot, not durable URL-derived IDs. MessageId fixture equality/hash includes peer, namespace and integer ID. The production URL setter deduplicates duplicate input URLs before preview IDs are assigned; no duplicate-per-occurrence identity is invented. Message.anyMedia is fixture media.first for these direct photo/document messages. Signal execution and account enqueue are synchronous in-memory capture. Attachment URL strings are synthetic and never read from disk. Strings and icon payloads are fixtures; production source references existing strings() and MenuAnimation. NSAccessibilityCustomAction is a callback fixture, not a live accessibility tree.

The baseline has no replacement helper, so the harness wraps its exact existing self.urls[index] = new assignment with the same test-facing signature. It supplies a constant true prepared-state closure because the baseline has no prepared-state equality gate. Missing individual menus are inherited empty methods of the row superclass; the harness does not invent a baseline toggle. Invalid table indices are invoked only when the source includes the new guard, otherwise that guard assertion fails without crashing the negative control. Source-wiring checks count the three editor helper call sites and check the send guard/transition assignment strings separately from runtime assertions. They are not claimed as editor or queue integration tests.

Known integration boundaries
The reviewer fix preserves PR405's media-based caption eligibility, ten-item slow-mode limit and caption/comment dispatch semantics without changing the active cooldown gate. The publication base includes merged PR330 and PR331. Its message-ID album URL mapping and URL-based reorder callback are retained. Row initialization now projects original URL/spoiler pairs by MessageId into the filtered layout message order, so existing menu, controls, rendering overlays and immediate reorder stay aligned; the caption-close confirmation is unchanged. The existing preview-album-target harness is adapted for the spoiler-array constructor, optional toggle callback, captured edit URL and captured table URL list; its assertions remain unchanged and it still supports the upstream source shape. Album-row table resort is disabled because its indices are albums, not attachments; per-tile reorder remains. Ungrouped table reorder captures the displayed URL snapshot so a later deletion cannot retarget the drop. The harness extracts either baseline or fixed table closure without rewriting its capture list. PR333 grouping preference and PR274 multi-album caption behavior are intentionally untouched. Existing per-album caption behavior is not claimed fixed. The legacy sendMedias fallback is still Bool-only, but all production attachment preview consumers (ChatUI and StoriesUI) install the extended sendMediasWithAnalytics path; no new cross-screen dependency is introduced.
