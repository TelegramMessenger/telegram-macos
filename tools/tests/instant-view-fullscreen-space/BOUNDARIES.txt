Run with python3 -I run.py --source-root <worktree-or-combined-source> --output <external-owned-directory>.

The executable compiles the exact production arrow and Space/Shift-Space handler registrations from InstantViewInBrowser.viewDidAppear, including closure bodies, weak captures, modifier sets and priorities. The exact app baseline 246e3e957ae5cea1ecff6d7a6a6db3e47be69bb5 is compiled separately and must run to assertion failures for both fullscreen navigation directions. Compiler failure is never accepted as a regression result. Baseline/support git reads are from the runner's own repository, independently of --source-root.

Routing is not invented: the KeyboardKey enum, HandlerPriority/KeyHandler/comparators, KeyHandlerResult, Window.set(handler:), Window.sendEvent's complete global/key-specific dispatch block and Window.removeAllHandlers' key-removal block are extracted from the authoritative base. The rest of Window/AppKit is an explicit boundary double. NSEvent carries raw key codes/modifier flags/window, NSTextView carries isEditable, and Window carries styleMask/firstResponder/isKeyWindow. Native sendEvent only counts forwarding. No NSApplication, real window, live event posting, account or GUI is created.

The controller/page boundary records scrollPage(direction:) calls and allows changing the active page. No article layout, actual pixels, responder acquisition, sheet routing, lifecycle notifications, native fullscreen transition or embedded WebView is exercised. Removal tests apply the real key-removal body, not view lifecycle delivery. Higher-priority media/global handlers are stand-ins that exercise the actual router's consumed/rejected/invokeNext behavior; no media player is launched. These tests establish handler logic, not real keyboard acceptance or live media behavior. Normal and fullscreen editable-text focus yields to native delivery; noneditable text still navigates. Existing .low/.medium priorities and arrow registrations stay intact.

Each swiftc is serial with -j1 and explicit macOS SDK/target. Inherited GIT_* variables are stripped. Generated source, binaries, logs, HOME, caches and temporary files live only under --output. Full package/app compilation and manual acceptance remain separate.
